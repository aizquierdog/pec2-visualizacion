# PEC 2 · Visualización de Datos (UOC)

Adrián Izquierdo Girona · Máster Universitario en Ciencia de Datos

Tres visualizaciones hechas con D3.js:

- `linechart.html` · Line chart · Euríbor a 12 meses (1999-2026). Datos: Banco Central Europeo (ECB Data Portal).
- `flowmap.html` · Flow map · Migraciones entre comunidades autónomas (2024). Datos: INE, tabla 69741.
- `hexbin.html` · Hexagon binning · Hora de salida y retraso de 231.083 vuelos (2001). Datos: U.S. Bureau of Transportation Statistics, vía vega-datasets.

Los datos de las dos primeras están dentro de cada página y en la carpeta `data/`. Los vuelos se cargan desde el CDN público de vega-datasets.
